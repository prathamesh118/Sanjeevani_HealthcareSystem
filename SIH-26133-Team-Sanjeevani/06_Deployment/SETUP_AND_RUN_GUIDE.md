# Setup and Run Guide – Sanjeevani

## Prerequisites
Install Node.js, npm and a modern browser.

## Run Locally
```bash
cd 04_Source_Code/frontend
npm install
npm run dev
```

Open the local URL shown by Vite in the terminal.

## Optional Checks
```bash
npm run lint
npm run build
```

## Voice Feature
Use a browser with supported speech features and allow microphone access when requested.

## Prototype Data
Current data is based on demo/seed data and browser storage. Clearing browser storage may reset prototype state.
