# Implemented Prototype Features – Sanjeevani

The following features are represented in the current frontend MVP:

## Role-Based Portals
- Patient
- ASHA / frontline healthcare worker
- ANM
- Doctor
- Administrator

## Patient Care Features
- Patient registration and record viewing
- Symptom capture
- Vital recording
- Consultation support
- Referral creation and status tracking
- Follow-up management

## Decision Support
The prototype contains rule-based triage and priority classification. It is intended to support workflow decisions and does not replace clinical diagnosis or professional medical judgement.

## Accessibility
- Voice-assisted interaction
- English support
- Hindi support
- Marathi support

## Data Scope
The MVP uses demo/seed data and browser-based persistence. It is not yet a production healthcare information system.
