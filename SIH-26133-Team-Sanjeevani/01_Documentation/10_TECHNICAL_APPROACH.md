# Technical Approach – Sanjeevani

## Current Prototype
- **Frontend:** React + TypeScript
- **Build Tool:** Vite
- **UI:** Tailwind CSS and component-based interfaces
- **Icons:** Lucide React
- **Motion/UI effects:** Motion library
- **State/Data:** Demo seed data and browser localStorage

## Functional Flow
**User → Role-Based Interface → Request/Input → Workflow Processing → Data/State → Triage/Decision Support → Result or Next Care Action**

## Voice and Multilingual Interaction
The prototype uses browser-based voice interaction features and includes English, Hindi and Marathi language support where implemented.

## Important Scope Note
The presentation architecture may describe a future production system with backend, workflow, data and AI layers. Those production components should not be represented as already implemented unless they are added to the source code.
