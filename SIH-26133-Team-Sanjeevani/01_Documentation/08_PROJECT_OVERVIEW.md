# Project Overview – Sanjeevani

## Project and Team Name
**Sanjeevani** is both the project name and the team name for SIH Problem Statement ID **26133**.

## Project Summary
Sanjeevani is a healthcare coordination prototype designed to improve accessibility and continuity of public healthcare services, particularly for rural and underserved users. It connects patients, frontline healthcare workers, doctors and administrators through a role-based digital workflow.

## Problem Addressed
Patients may face fragmented records, delayed referrals, missed follow-ups, travel burden, language barriers and difficulty accessing the right level of care. Healthcare teams may also lack a connected view of patient progress.

## Proposed Solution
Sanjeevani provides a connected workflow for patient registration, symptom and vital capture, priority support, referral tracking, consultation support and follow-up management. Voice-assisted and multilingual interaction is included to improve accessibility.

## Target Users
- **Patients and Caregivers** – access and understand the next care step.
- **Healthcare Workers** – register patients, capture information and coordinate follow-ups.
- **Doctors** – review patient information and manage referred cases.
- **Administrators** – monitor coordination and workflow activity.

## Current Prototype Scope
The current MVP is a React-based frontend prototype using demo data and browser-based persistence. Production backend services, secure databases and external healthcare integrations remain future implementation items.
