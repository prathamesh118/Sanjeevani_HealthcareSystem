# SIH 26133 – Sanjeevani

## Project and Team Name
**Sanjeevani**

## Project Title
Accessibility and Quality of Public Healthcare Services, Particularly in Rural and Underserved Areas

## Problem Statement ID
**26133**

## Category
Software – MedTech / BioTech / HealthTech

## Project Summary
Sanjeevani is a healthcare coordination prototype that connects patients, frontline healthcare workers, doctors and administrators through role-based workflows for patient records, symptom and vital capture, priority support, referrals and follow-ups. Voice-assisted and multilingual interaction are included to improve accessibility.

## Repository Structure
- `01_Documentation/` – problem analysis, solution, technical approach, feasibility, impact and prototype documentation.
- `02_Research/` – research, existing-solution analysis and USP work.
- `03_Design/` – system design and diagram documentation.
- `04_Source_Code/frontend/` – React + TypeScript + Vite prototype.
- `05_Testing/` – test plan, test cases, validation notes and demo scenarios.
- `06_Deployment/` – setup guide and production roadmap.

## Run the Prototype
```bash
cd 04_Source_Code/frontend
npm install
npm run dev
```

## Scope Note
The repository currently represents a frontend MVP/prototype using demo data and browser-based persistence. Production backend services, secure healthcare databases, advanced AI services and external integrations are documented as future scope unless implemented in source code.
