# Demo Scenarios – Sanjeevani

## Scenario 1: Patient Journey
Register or select a patient → capture symptoms/vitals → view priority support → move toward consultation/referral.

## Scenario 2: Referral Journey
Healthcare worker/ANM records assessment → creates referral → doctor reviews or updates → referral progress is tracked.

## Scenario 3: Follow-Up Journey
Assign or identify a follow-up → complete the activity → show updated status.

## Scenario 4: Accessibility Journey
Activate voice assistance or change language → demonstrate a simpler interaction path for users with different language or literacy needs.
