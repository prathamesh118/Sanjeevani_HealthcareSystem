# Test Plan – Sanjeevani

## Objective
Verify that the prototype's major user workflows operate correctly and are understandable for demonstration.

## Main Areas
- Role selection and navigation
- Patient registration and records
- Symptoms and vitals
- Rule-based triage
- Referrals and status updates
- Follow-ups
- Voice interaction and permissions
- Multilingual UI behavior

## Test Method
Run each workflow using normal, missing and boundary-style inputs where applicable. Record only results that are actually verified.
